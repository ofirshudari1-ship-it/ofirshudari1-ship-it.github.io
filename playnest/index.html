The Problem

Every game library is a mess, by design

Steam only knows about Steam. Epic only knows about Epic. Nobody knows about everything else.

📦

Installer files shown as games

Naive scanners list the setup.exe or uninstaller instead of the game itself — click it, and you get an install wizard, not your game.

🪞

Duplicates everywhere

The same install shows up in the Windows registry and in a folder scan — without real dedup, one game shows up two or three times.

🐌

Slow loads because of artwork

Fetching cover art means a network call per item — if the library waits on that, the whole app feels stuck.

🎭

"Gaming tools" that are just skins

Plenty of similar apps bolt on "Discord integration" or "RGB control" that's really just made-up numbers with no real connection to your system.

How It Works

Three steps, no account, no cloud

Playnest runs locally on your machine only. No server, no syncing, no account to sign into.

1️⃣

Scan

During the initial setup wizard, Playnest scans Steam, Epic, the Windows registry, and install folders — filtering out setup/uninstall files and duplicates automatically.

2️⃣

One unified library

Every game and app lands in a single view with covers, search, and filters — and clicking launches the actual game, not the installer.

3️⃣

Stays up to date on its own

A periodic background scan automatically picks up anything new you install, and app updates download in the background via GitHub Releases — no need to come back to this page.

Full Transparency

A previous version had fake tools. We removed them.

Version 3.1.0 shipped 9 "gaming tools" that turned out to be UI only — with no real connection to the system. Instead of leaving them in as decoration, we deleted them outright.

Discord Rich Presence, VPN Checker, RGB Control, Streaming Optimizer, Game Recorder
Each one showed a permanent "connected" state or random numbers — with no real connection to any API, VPN, RGB hardware, or recording pipeline.
AI Gaming Coach, Friend Activity Tracker, Game Comparison, Advanced Statistics
"AI advice" and invented friends, prices hardcoded for just three games, and a duplicate stats page showing random numbers on top of the real analytics page that already existed.
Performance Mode, Streak Tracker, System Monitor
Rebuilt to read and write real things — the Windows registry, powercfg, a genuine usage log, and hardware sensors.
Tools Management (list page)
Even real tools can be redundant: the "Tools" page showed a static list of every tool with no interaction — exactly what the sidebar already shows. Removed, and two similarly named tools ("Game Mode" appeared twice in two different places) were merged into one Performance Mode page.

Automatic Updates

Updates itself — no need to come back here

Starting with version 3.4.4, Playnest automatically checks in the background for a new version on the project's GitHub Releases (electron-updater — the same update technology most serious Electron apps use).

Background check
A few seconds after launch, Playnest quietly checks whether a new version is out — without delaying the app or asking the user for anything.
Automatic download + install prompt
If there's an update, it downloads in the background, and a short notification appears with "Install now" or "Later" — no forced restart.
No internet? Nothing breaks
If there's no connection or GitHub is unreachable, the check fails silently and logs to a local error log — Playnest keeps working as usual.
